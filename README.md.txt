📌 Task Management Web Application

Full Stack Internship Assignment – Global Trend

A simple, responsive Task Management Web Application built using Python (Flask) and MySQL, with an attractive frontend and RESTful backend. This project allows users to add, view, update, and delete tasks efficiently.

🚀 Features

📝 Create, update & delete tasks

📋 View all tasks in a clean UI

🎨 Modern frontend design (HTML, CSS, JavaScript)

⚙️ Flask REST API integration

🗄️ MySQL database connectivity

🔐 Secure environment variable handling

📦 GitHub-ready project structure

⚙️ Setup Instructions
1. Clone the repository
git clone https://github.com/shivi245/Task-Manager.git
cd Task-Manager

2. Backend setup
cd backend
python -m venv venv
venv\Scripts\activate   # Windows
pip install -r requirements.txt


Create a .env file:

DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_mysql_password
DB_NAME=task_manager


Run backend:

python app.py

3. Frontend setup

Open frontend/index.html in browser
OR run via Live Server in VS Code.
